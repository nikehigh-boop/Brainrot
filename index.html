    How the carpet picks

    1. Tier. The highest luck level on the server plus any bonus luck picks an odds table. Since Tier 13 arrived (Oct 17) luck levels go up to 700.
    2. Brainrot. The game rolls inside the chosen tier using the tier tables below.
    3. Mutation. The type roll depends only on the event that's running. See Mutations.

    The datamine lists the tier odds every 50 levels, so this page uses the nearest listed level at or below yours. Carpet odds are only published up to level 500, so levels 501–700 use the level 500 table. Tier 13 unlocks at luck level 685 (community-reported) and its Eternal-and-up odds come from RotSwap's Oct 17 guide.

    Ferinsini Luckini

    Activating one rolls a luck bonus. They don't stack and don't affect lucky rots, llama rots, wheel spins or machines. One with traits also starts those trait events for 5 minutes (except Wave).
